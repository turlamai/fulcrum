Tab 环

  1. query → 结果列表（整体一个 tab stop）→ footer 链接
  2. actions 层：首条 action → modebar 的 esc → query
  3. Shift+Tab 严格反向，不跳层

进入与回位

  1. ⌘K 后焦点落首条 action，选中行同步
  2. Esc 返回结果，按 item id 恢复原行焦点，不取第一行
  3. 行被过滤掉时，焦点落到主操作而不是脱离文档的节点

可见性

  1. 全站 2px --accent-text ring，offset 2px；行内 -2px
  2. 键盘焦点与选中是两件事：选中是 amber 底 / 内描边，焦点是外环
  3. 宿主用 roving tabindex；原型为静态评审稿，行仍逐条可 Tab 以便查看焦点环
