为什么是 Fulcrum

你伸手可及的一切， 只差一次按键。

Fulcrum 平时隐于幕后，一个热键唤出——此后应用、文件、剪贴、计算与命令，都只差几个字母。

疾速模糊搜索

敲几个字母，结果随输入即时出现——跨应用、文件与操作的亚秒级模糊匹配。

所有应用

每个已安装的应用，一次查询直达。启动、切换、完成——不必再在菜单和 Dock 里翻找。

剪贴板历史

复制过的一切都保存在本机、随时可搜。上周的链接，像昨天的随取随贴。

文本片段

把反复输入的回复、模板和代码片段存起来——按名字随处展开。

计算器：函数与常量

边输入边计算——支持 sqrt、sin、log 与 π、e 等常量，无需切换应用。

网络搜索 bang

!g 谷歌、!gh GitHub、!w 维基百科、!so Stack Overflow——一个 bang 直达对应的搜索框。

系统命令

锁屏、睡眠、静音——系统操作也在同一块面板里，不必翻菜单。

插件生态

语言无关的插件协议：JSON over stdio。用什么语言写插件都行，Fulcrum 负责运行。

本地工具与可选在线集成，默认私有

搜索索引、剪贴板历史与片段保存在本地。插件、AI 与文件夹同步可将选定数据发送至外部服务。核心功能无需注册账号。

跨平台

一个 Racket 后端。 三套一等原生 UI。

基于 Rivet 框架构建：一个共享的 Racket 后端嵌入每个应用，每个平台都是一等原生 UI。没有任何 WebView。

开始使用

从一次有效使用开始。

开发预览。已有启动器、剪贴板、插件和 BYOK 功能保持免费；尚未开放 Pro 购买。 提供 macOS、Windows、Linux 桌面开发预览。权限与快捷键行为取决于系统及 Linux 图形会话。

01

打开 Fulcrum，用设置中的全局快捷键呼出窗口；快捷键冲突在设置中解决。

02

输入 12*12 确认得到 144，再搜索并启动一个已安装应用。

03

分别按需启用剪贴板历史、插件和 AI，先了解各自需要的数据与权限。

当前为开发预览。新增多步骤工作流自动化仍在规划，尚不是可购买能力。AI 生命周期拆分见 #89。
