为什么是 Fulcrum

你伸手可及的一切， 只差一次按键。

Fulcrum 平时隐于幕后，一个热键唤出——此后应用、文件、剪贴、计算与命令，都只差几个字母。

一框即一切

应用、文件、网页与操作，同一个查询框全部接住——敲几个字母，候选随输入即时刷新，↵ 直接启动，不必再翻菜单和 Dock。

剪贴板历史与片段

复制过的每段文字都留在本机、可搜可置顶，回车直接粘回你刚才在用的应用；反复输入的回复与模板存成片段，按关键词原地展开（macOS 与 Windows）。

内联计算

边输入边算：精确算术、sqrt、sin、log 与 π、e 等常量；答案就在结果最上面，↵ 复制，不用切换应用。

BYOK AI，流式回答

接入自己的 OpenAI / Anthropic / Ollama 密钥——只存本机，绝不参与同步。答案流式打进面板，模型还在生成就能开始读，完成后自动进剪贴板；以 ？ 结尾的问句自动出现 AI 行。

网页搜索 bang

!g 谷歌、!gh GitHub、!w 维基百科、!so Stack Overflow——一个 bang 直达对应的搜索框；没被别处匹配的普通文字，也会兜底成一条通用搜索行（默认 !g，可在设置里换）。

⌘K 次级操作

选中剪贴板行，⌘K（Windows / Linux 是 Ctrl+K）调出这一行的动作：复制、粘贴回前台、固定、删除。Esc 逐层退回，底部的快捷键提示实时跟着换。

窗口与系统命令

左半屏、右半屏、最大化、居中、还原——窗口排布与锁屏、睡眠同在这块面板；只列出当前平台真实存在的命令，不给点了没反应的假条目。

插件生态

语言无关的插件协议：JSON over stdio。用什么语言写插件都行，Fulcrum 负责运行。

本地工具与可选在线集成，默认私有

搜索索引、剪贴板历史与片段保存在本地。插件、AI 与文件夹同步可将选定数据发送至外部服务。核心功能无需注册账号。

跨平台

一个 Racket 后端。 三套一等原生 UI。

基于 Rivet 框架构建：一个共享的 Racket 后端嵌入每个应用，每个平台都是一等原生 UI。没有任何 WebView。

开始使用

从一次有效使用开始。

开发预览。已有启动器、剪贴板、插件和 BYOK 功能保持免费；尚未开放 Pro 购买。 提供 macOS、Windows、Linux 桌面开发预览。权限与快捷键行为取决于系统及 Linux 图形会话。

01

打开 Fulcrum，用设置中的全局快捷键呼出窗口；快捷键冲突在设置中解决。

02

输入 12*12 确认得到 144，再搜索并启动一个已安装应用。

03

分别按需启用剪贴板历史、插件和 AI，先了解各自需要的数据与权限。

当前为开发预览。新增多步骤工作流自动化仍在规划，尚不是可购买能力。AI 生命周期拆分见 #89。
